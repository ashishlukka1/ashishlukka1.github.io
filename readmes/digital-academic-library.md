## overview

a MERN platform that brings academic resources, book booking and student communities into one place. role-based access keeps students, faculty and guests in their own lanes, and a gemini-powered chatbot answers student questions on the spot.

**winner, webathon 3.0.**

## highlights

- **three roles, one platform:** students, faculty and guests each get access that matches their role.
- **booking from start to finish:** search for a book, request it, check availability and receive a booking confirmation.
- **SMS confirmations:** twilio texts the student when a booking is confirmed.
- **student communities:** discussion forums and real-time chat rooms for student groups.
- **AI help:** a gemini-powered chatbot answers student queries.
- **a library that grows with demand:** faculty can publish student requests as new library resources.

## how a request becomes a resource

1. a student requests a book or resource the library does not have yet.
2. faculty pick up the request and publish it.
3. the new resource joins the library for everyone with access.
